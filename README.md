# Spare Parts Trader PWA

Mobile-first Arabic PWA for a single spare-parts trader.

Current test build works locally on the device:
- Search products
- Add product + photo
- Add supplier + phone/WhatsApp/address
- Record supplier purchase price
- Product history
- Supplier profile with recent supplied parts
- Backup/restore JSON
- Installable PWA / offline cache
